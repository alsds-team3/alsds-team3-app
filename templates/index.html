About Team 3

ALSDS — AI-Assisted Location Decision Support System is a Worcester-focused site feasibility tool built by Team 3 for the Urban Analytics AI Consultancy capstone.

We combine an Azure SQL backend of Worcester POIs, CBG centroids, and calibrated Huff parameters with an Azure OpenAI advisor (Atlas AI) that runs the gravity model, compares candidate sites, and explains results in plain language for non-technical owners.

What you can do

  • Drop a candidate pin anywhere in the Worcester service area.
  • Pick a calibrated business category — or type a plain label like "bakery".
  • Compare alternative locations side-by-side (same NAICS only).
  • Ask the chatbot follow-up questions about competitors and limits.

Stack

Flask · Azure SQL · Azure OpenAI (GPT-4o) · Leaflet · Chart.js
